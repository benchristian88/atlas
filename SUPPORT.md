# Support

Start with the [documentation](docs/README.md), particularly installation,
backup/restore and upgrades. Report reproducible bugs and discuss feature requests
in [GitHub Issues](https://github.com/benchristian88/atlas/issues).
For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

Include your Atlas version/channel/build, install method, host OS, relevant
browser version, reproduction steps, expected/actual behaviour and minimal
redacted logs. For deployment failures, include which prerequisite or health
check failed. Never post credentials, API tokens, session cookies, setup codes,
MFA material, database dumps, backup archives or private inventory publicly.

Supported production installation uses Docker Compose or native/systemd release
packages. Source execution is a development workflow. Live integration operation
and guided onboarding are forthcoming; simulation and existing adapter tests do
not establish live discovery support. There is no promised support SLA or
commercial support entitlement.
