# Historical implementation prompts

This directory preserves completed implementation prompts and context that may
help explain past delivery work. These files are historical evidence only.

They must not be treated as current product requirements, architecture,
implementation status, or instructions for a new coding session. Current
authority is:

- [`../../product/development-roadmap.md`](../../product/development-roadmap.md)
  for forward planning;
- [`../../product/release-c2-plan.md`](../../product/release-c2-plan.md) for the
  current C2 release boundary and C2.1 implementation history;
- [`../../product/feature-ledger.md`](../../product/feature-ledger.md) for
  implementation evidence;
- [`../../architecture/operational-graph.md`](../../architecture/operational-graph.md)
  for graph architecture; and
- [`../../decisions/0001-shared-operational-graph.md`](../../decisions/0001-shared-operational-graph.md)
  for the governing architectural decision.

Archived files:

- `atlas-codex-context.md` — pre-delivery C2.1 repository and implementation
  context.
- `c2-1-shared-operational-graph-codex-prompt.md` — the executable prompt used
  to guide the completed C2.1 implementation.

All lasting C2.1 decisions and delivered behavior are captured by the canonical
documents above. No unique architectural decision depends solely on these
prompts.
